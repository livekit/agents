# Frozen Node-API headers

These public headers come from the official Node.js 26.12.1 declaration set. The host uses their stable N-API 8 interface. The parent folder's
`header-provenance.json` records public source references and exact hashes;
`NODE-LICENSE` retains the complete upstream license notice.

We copy the four-header declaration closure plus `node_version.h` for version
identity. The build does not link libnode, V8 or libuv.
