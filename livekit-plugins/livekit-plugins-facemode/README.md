# FaceMode plugin for LiveKit Agents

Support for the [FaceMode](https://facemode.io/) virtual avatar.

See the [FaceMode docs](https://docs.facemode.io/) for more information.

## Installation

```bash
pip install livekit-plugins-facemode
```

## Pre-requisites

You'll need an API key from FaceMode. It can be set as an environment variable: `FACEMODE_API_KEY`
