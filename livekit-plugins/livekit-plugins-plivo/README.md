# Plivo plugin for LiveKit Agents

Support for [Plivo](https://www.plivo.com/)'s voice AI models in LiveKit Agents.

Refer [TTS](https://docs.livekit.io/agents/models/tts/plugins/plivo/) integration docs for further details.

## Installation

```bash
pip install livekit-plugins-plivo
```

## Pre-requisites

You'll need an auth ID and an auth token from Plivo. They can be set as environment variables: `PLIVO_AUTH_ID` and `PLIVO_AUTH_TOKEN`
