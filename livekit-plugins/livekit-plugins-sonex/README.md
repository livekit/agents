# SonexLabs plugin for LiveKit Agents

Support for streaming text-to-speech synthesis with [SonexLabs](https://sonexlabs.com)' Panini TTS.

See [https://docs.livekit.io/agents/integrations/tts/sonex/](https://docs.livekit.io/agents/integrations/tts/sonex/) for more information.

## Installation

```bash
pip install livekit-plugins-sonex
```

## Pre-requisites

You'll need an API key from SonexLabs. It can be set as an environment variable: `SONEX_API_KEY`
