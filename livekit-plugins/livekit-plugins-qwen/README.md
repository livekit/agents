# Qwen plugin for LiveKit Agents

Support for Qwen speech and language models on [Alibaba Cloud Model Studio](https://www.alibabacloud.com/en/product/modelstudio) in LiveKit Agents: realtime speech-to-text (`qwen3-asr-flash-realtime`), realtime text-to-speech (`qwen3-tts-flash-realtime`) and chat completions on the OpenAI-compatible endpoint.

## Installation

```bash
pip install livekit-plugins-qwen
```

## Pre-requisites

Set `DASHSCOPE_API_KEY` to a Model Studio API key.
